[Download MacBattery Control](https://github.com/dustpkh/MacBattery-Control/releases/latest)

- 프로그램명: MacBattery Control
- 버전: 1.0
- 운영체제: Windows
- 배포 방식: 무료 비공개 소프트웨어 (Closed-source Freeware)

## 주요 기능

- 배터리 상태 모니터링
- 배터리 정보 확인
- 시스템 트레이 지원
- Windows 시작 프로그램 지원

## 설치 방법

1. 최신 버전 다운로드 링크를 클릭합니다.
2. 설치 파일을 다운로드합니다.
3. 설치 프로그램을 실행합니다.
4. 설치가 완료되면 프로그램을 실행합니다.

## 라이선스 및 배포 정책

MacBattery Control은 무료 비공개 소프트웨어입니다.

- 무료로 사용할 수 있습니다.
- 소스 코드는 공개하지 않습니다.
- 무단 수정 및 재배포를 허용하지 않습니다.
