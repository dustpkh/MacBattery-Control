# MacBattery-Control
Free Battery Management Software for Windows# MacBattery Control

**Free Battery Management Software for MacBook Running Windows**

 [Download MacBattery Control Beta 1.0 (Releases)](https://github.com)

MacBattery Control is a Windows application designed to manage MacBook battery charging through Apple SMC communication.

Developed for MacBook users running Windows, including Boot Camp on Intel Macs.

## Features

- **Battery Charging Limit Control:** Set and maintain your maximum charge limit between 60% and 90% in 10% increments (60%, 70%, 80%, 90%).
- **Battery Status Monitoring:** Real-time battery health and charging status tracking.
- **Apple SMC Communication:** Direct hardware-level charge control via Apple SMC.
- **System Tray Operation:** Lightweight background execution accessible from the Windows system tray.

## Requirements & Driver Notice

**SMC Driver Dependency**

Beta 1.0 relies on the SMC driver provided by an external Apple Fan Control utility, such as Macs Fan Control, to communicate with the hardware.

Please ensure the required SMC driver is installed before running MacBattery Control.

Hardware compatibility may vary depending on the MacBook model.

## Apple Fan Control — Version 2.0 Planned

**Current Version (Beta 1.0)**

Fan control currently relies on an external Apple Fan Control utility, such as Macs Fan Control, to provide the required SMC driver.

**Future Version (2.0)**

We plan to develop and integrate our own native Apple fan control functionality directly into MacBattery Control, eliminating the need for external fan control software.

This is one of our major goals for Version 2.0.
